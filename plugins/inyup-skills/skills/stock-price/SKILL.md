# 평가액 갱신 (stock-price)

원장: `C:\Users\biy06\OneDrive\바탕 화면\클로드실습\주식\트레이딩 기록\포트폴리오기록.xlsx`

주 2회 실행한다. 하는 일은 두 가지뿐이다.
**① 종목별 주당단가를 [시세기록]에 append → ② [대시보드]에 스냅샷 한 줄 추가.**
평가액·수익률·누적수익률은 전부 엑셀 수식이 계산하므로 여기서 산수하지 않는다.

## 1. 무엇을 입력해야 하는지 먼저 보여준다

```bash
python "C:\Users\biy06\.claude\skills\stock-price\scripts\update_prices.py" --list
```

보유 종목 · 통화 · 수량 · 직전 기록일 · 직전 단가가 JSON으로 나온다.
이걸 **표로 정리해 사용자에게 보여주고**, 단가를 채워 달라고 한다. 직전 단가를 같이
보여주면 사용자가 오타를 바로 알아챈다.

```
| 종목 | 통화 | 수량 | 직전(07-29) | 오늘 |
|---|---|---|---|---|
| SK하이닉스 | KRW | 30 | 251,000 | ? |
| HIMS | USD | 120 | 48.20 | ? |
```

함께 받을 것:
- **USD/KRW 환율** (생략하면 설정 시트의 기존 값을 그대로 쓴다)
- **보유 현금** (원화)
- **입출금** — 이번 회차에 계좌로 새로 넣거나 뺀 금액. 없으면 0.
  **누적수익률이 이 값으로 계산되므로 입금이 있었는데 빠뜨리면 수익률이 부풀려진다.**

### 자동 조회 (선택)

사용자가 원하면 미국 종목은 `UsStockInfo-get_stock_info` MCP로 현재가를 채워 넣을 수
있다. 다만 **기본값은 수동 입력**이다. 자동으로 채웠으면 값을 사용자에게 보여주고
확인받은 뒤 반영하고, payload에 `"입력경로": "자동"` 을 넣는다.
한국 종목은 이 MCP로 조회되지 않으므로 사용자 입력을 받는다.

## 2. 반영

payload를 임시 폴더에 UTF-8 JSON으로 쓰고 실행한다.

```bash
python "C:\Users\biy06\.claude\skills\stock-price\scripts\update_prices.py" --input snapshot.json
```

```json
{
  "날짜": "2026-08-02",
  "환율": 1385,
  "보유현금": 5000000,
  "입출금": 0,
  "메모": "",
  "시세": { "SK하이닉스": 258000, "HIMS": 51.0 }
}
```

- 시세의 키는 **[보유종목] 마스터의 종목명과 정확히 같아야** 한다. 다르면
  `마스터에_없는_종목` 으로 돌아오고 그 종목은 기록되지 않는다.
- 단가는 **현지 통화 그대로** 넣는다. 원화 환산은 엑셀이 한다.
- **같은 날짜로 다시 실행하면 덮어쓴다.** 중복 행이 생기지 않으므로 오타를 고칠 때
  그냥 다시 돌리면 된다. 이때 `입출금`을 생략하면 기존 값이 보존된다.

## 3. 결과 확인과 보고

스크립트 출력에서 세 가지를 반드시 사용자에게 전달한다.

| 키 | 의미 | 대응 |
|---|---|---|
| `시세_누락` | 마스터에 있는데 단가를 안 준 종목 | 빠뜨린 것인지 확인. 누락되면 그 종목 평가액이 **직전 값 그대로 남아** 총액이 틀어진다 |
| `수량_미입력` | 마스터에 수량이 없는 종목 | 평가액이 0으로 잡힌다. [보유종목] 시트에 수량을 넣어야 한다 |
| `마스터에_없는_종목` | 이름이 안 맞는 종목 | 철자 확인 |

그다음 한 줄 요약을 준다 — 총자산, 직전 대비, 누적수익률.
**단, 엑셀 수식 결과는 파일을 열어야 계산되므로 스크립트는 이 값을 모른다.**
숫자를 말하려면 직접 계산해서 "엑셀에서 재계산될 값"이라고 밝히거나,
그냥 "파일을 열면 대시보드에 반영돼 있다"고만 말한다. **추정치를 확정값처럼 말하지 않는다.**

## 4. 주의

- 수량이 바뀌었으면(추가 매수·부분 매도) **[보유종목] 마스터의 수량·평균단가를 먼저
  고친다.** 시세기록은 기록 시점의 수량을 그대로 박아 넣기 때문에, 마스터가 옛날
  수량이면 그 스냅샷 전체가 틀린다.
- 청산한 종목은 마스터에서 상태를 `청산`으로 바꾼다. `--list`에서 자동으로 빠진다.
  **매도한 날에는 그 종목 단가를 넣지 않는다.** 매각 대금은 `보유현금`에 반영한다.
  둘 다 넣으면 그날 총자산이 이중 계상된다.
- 이 스킬은 **평가액만** 다룬다. 투자 판단 근거(진입/점검/회수/사후추적) 기록은
  **`stock-record`** 스킬이다.
