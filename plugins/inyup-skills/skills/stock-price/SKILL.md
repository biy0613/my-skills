# 가격대 점검 — 홍진채 방식 (stock-price)

> 내부 분석용 · 투자 권유 아님. 결과는 계산이지 매매 권고가 아니다.

## 무엇을 하는가

"PER 4배라 싸다"는 말은 분모(이익)가 이례적으로 높을 때 왜곡된다(교양이를 부탁해 2026-11-13, 홍진채 대표).
그래서 **이례적 이익 구간과 정상 구간을 나눠** 계산한다.

```
적정가 = (내년 이익 + 내후년 이익 × 2 + 정상 이익 × 배수) ÷ 1.1³
비율   = 적정가 ÷ 종가
```

| 비율 | 분류 | 영상의 코스피 예 |
|---|---|---|
| 1.5 이상 | 매우 싸다 | 시총 3,000조 (1.83) |
| 1.15 ~ 1.5 | 싸다 | 시총 4,500조 (1.22) — "할 만한 가격대" |
| 0.85 ~ 1.15 | 보통 | |
| 0.85 미만 | 비싸다 | 시총 8,000~9,000조 (0.6~0.7) |

## 실행 — 한 줄

```bash
python ~/.claude/skills/stock-price/scripts/pricezone.py --ref
```

- `--ref` 삼성전자·SK하이닉스를 참고로 함께 낸다 (영상의 중심 종목).
- `--extra MU,TSM` 목록 밖 종목 추가.
- 출력은 마크다운 표(보유 / 주문 / 참고 / 계산 불가). **그 stdout 만 읽는다** — 토큰을 아끼려고 중간 파일을 열지 않는다.
- 맨 위에 `⚠️ 이익 전망이 n일 전` 경고가 뜨면 먼저 아래를 돌리고 다시 실행한다 (3~5분, 백그라운드로).
  ```bash
  python 종목분석툴/_도구/성장률PER지도/per_map.py
  ```

읽기 전용이다. 엑셀·프로젝트 파일에 쓰지 않으므로 `safe_edit` 락이 필요 없고, 다른 세션이 돌고 있어도 실행해도 된다.

## 종목 1개를 내 가정으로 — 멍거버거 방식과 함께 쓸 때

컨센서스를 그대로 넣는 위 훑기와 달리, **사용자와 대화로 정한 가정**으로 한 종목을 계산한다.
`stock-burger` 2회차의 5단계(가정 원장) → 6단계(선반영 역산) → 7단계(시나리오)에서 쓰고, 3회차 판정 카드 직전에 가정이 바뀌었으면 다시 돌린다.
멍거버거가 아니어도 "이 종목 내 가정으로 가격대 봐줘" 같은 요청에 쓴다.

### 순서

1. **초안을 띄운다** — 컨센서스와 스킬 기본 가정이 채워진 출발점.
   ```bash
   python ~/.claude/skills/stock-price/scripts/myzone.py --template <코드> "<종목명>"
   ```
2. **가정을 하나씩 묻고 정한다.** 한 번에 다 묻지 않는다. 각 질문에 컨센서스 값과 내 제안, 그 근거를 같이 보여 주고 사용자가 고른다. 고정 순서:

   | # | 정할 것 | 묻는 말 | 재료 |
   |---|---|---|---|
   | ① | 이례적 이익 구간이 몇 년인가 | "지금 이익은 평소보다 높은가, 그렇다면 언제까지 이어지는가" | 멍거버거 3단계 핵심 변수·수주잔고·증설 일정 |
   | ② | 그 구간의 연도별 이익 | "컨센서스 숫자를 그대로 믿는가, 핵심 변수로 다시 세면 얼마인가" | 물량 × 단가 × 이익률로 직접 계산 (4단계 교차검증 결과) |
   | ③ | 구간이 끝난 뒤 정상 이익 | "호황이 지나고도 남는 것은 무엇인가" | 과거 사이클 평균, 장기 계약, 구조적으로 달라진 점 |
   | ④ | 정상 이익에 붙일 배수 | "그때 이 회사는 평균 회사인가, 더 나은가" | 한국 10·미국 20이 기준. 올리려면 이유를 적는다 |
   | ⑤ | 좋은 경우·나쁜 경우 | "①~④ 중 무엇이 틀리면 가장 크게 달라지는가" — 변수 2~3개만 바꾼다 | 킬 스위치·2배 스토리 |
   | ⑥ | 확률 | "셋의 무게를 어떻게 두는가" | 사용자가 정한다. 내가 먼저 숫자를 박지 않고 제안만 한다 |

   - 이익이 평소 수준인 회사(사이클이 없는 성장주)는 ①을 "컨센서스가 보이는 3년"으로 두고 ③을 3년차 이익으로 둔다. 그때 쟁점은 ④ 배수다.
   - 사용자가 총액(순이익 몇 조)으로 말하면 `shares` 를 넣고 `ni`·`normal_ni` 로 적는다.
3. **가정 파일로 저장한다** — `종목분석툴/리포트/_소스/<종목>/_가격대가정.json`. 정한 가정마다 `ledger` 에 값·근거·확정일(누가)을 남긴다. 사용자가 확정하지 않은 값은 `확정` 을 비운다.
   - 이 폴더는 다른 세션이 쓰고 있을 수 있다. 세션 시작 경고가 떴으면 저장 전에 사용자에게 알린다.
4. **계산한다.**
   ```bash
   python ~/.claude/skills/stock-price/scripts/myzone.py "<가정파일 경로>"
   ```
   나오는 것: 시나리오별 적정가·분류 · 확률 가중 · **컨센서스 기준과의 차이**(어느 가정이 얼마나 달라 적정가가 몇 % 다른가) · **역산**(지금 주가가 요구하는 정상 이익·배수·구간 이익) · 분류 경계 주가 · 가정 원장.
5. **읽어 준다.** 표를 그대로 보여 준 뒤 세 가지를 말한다:
   - 내 가정과 컨센서스가 갈리는 지점 한 줄 — 그것이 이 종목의 '다른 견해'다. 갈리는 곳이 없으면 그렇다고 말한다.
   - 역산 결과를 말로 — "지금 주가는 호황 뒤 이익이 얼마라고 보고 있다". 음수면 "시장이 구간 이익 자체를 안 믿는다".
   - 분류를 가장 크게 바꾸는 가정 하나 — 다음에 확인할 사실(팩트체크 요청 후보)이 된다.
6. 가정이 바뀌면 파일을 고치고 `ledger` 에 한 줄 더한다(지우지 않는다). 다시 4번.

### 지킬 것

- **분류 경계 주가는 손절·진입 라인이 아니다.** 라인은 멍거버거 판정 카드에서 따로 정한다. 다만 라인을 정할 때 이 표를 참고 자료로 옆에 둔다.
- 사용자가 정하지 않은 가정을 내가 채워 놓고 결과를 '내 가정 기준'이라고 부르지 않는다. 미정인 시나리오는 표에 '가정 미정'으로 남는다.
- 멍거버거 6단계의 원래 역산(물량·수주잔고 기준)을 대체하지 않는다. 이 계산은 그 옆에 놓는 **이익 기준 역산**이다.

## 가정 — 스크립트 위쪽 상수

| 구분 | 정상 이익 | 배수 | 근거 |
|---|---|---|---|
| 메모리 (삼성전자·하이닉스·MU) | 내년 이익 × 12.5% | 10 | 영상: 전자·닉스 800조 → 100조 |
| AI 투자 연동 (`tags.json` 경기순환 + `CYC_EXTRA`) | 내후년 이익 × 50% | 한국·중국 10 / 미국 20 | 영상의 '사이클이 끝난 뒤 정상 수준'을 반도체·장비·광통신에 적용한 것. 50% 는 내 가정 |
| 그 외 | 내후년 이익 그대로 | 기본 × 1.0 / 1.25 / 1.5 | 증가율 10% 미만 / 10~25% / 25% 초과. **영상에 없는 가산** |

- 3년차 이익은 내후년과 같다고 놓는다. 할인율은 영상 그대로 연 10%.
- AI 연동·메모리는 **범위**가 같이 나온다: 조기 종료(3년차부터 정상 이익) ~ 호황 지속(정상 이익 100%).
- **요구배수** = 지금 주가가 성립하려면 3년 뒤 이후 가치가 내후년 이익의 몇 배여야 하는가. 음수면 3년 이익 합이 이미 주가보다 크다(시장이 컨센서스를 안 믿는다는 뜻).

가정을 바꿔 달라는 요청이 오면 상수(`MEM_NORMAL`·`CYC_NORMAL`·`TIERS`·`BASE_*`·`CUTS`)를 고치고, 이 표도 같이 고친다.

## 사용자에게 보여 줄 때

1. 표를 **보유 → 주문고려 → 참고** 순으로, 비율 높은 순서 그대로 보여 준다.
2. 표 뒤에 반드시 붙이는 것:
   - **가정을 바꿔도 결론이 안 바뀌는 종목** — 범위 양끝이 같은 분류에 있는 것 (예: 2026-11-13 엔비디아·하이닉스 싸다, AMD·아스테라·인텔 비싸다).
   - **신뢰가 낮은 줄** — 메모에 `외삽`·`직접 조회`가 있는 줄, 추정 기관이 1~2곳인 종목(성장률PER지도 `latest_summary.md` 의 n), 주가가 최근 급락해 추정치가 아직 안 내려왔을 수 있는 종목.
   - **조정 이익 주의** — 미장 소프트웨어(팔란티어·서비스나우·쇼피파이 등)는 주식보상을 뺀 이익이다. 회계 이익 기준이면 한 단계 비싸진다.
   - **이익 ≠ 현금** — 성장률PER지도가 '현금전환' 탈락으로 표시한 종목(2026-10 실리콘투 0.21, 노바렉스 0.50)은 싸게 나와도 그대로 믿지 않는다.
3. 분류는 "지금 가격대의 감"이다. 영상의 말대로 **싸다는 것만으로는 안 오른다** — 받아 줄 수급과 변화가 따로 있어야 한다. 매수·매도를 권하지 않는다.
4. 삼성전자·SK하이닉스 비중을 늘리는 얘기로 이어지면 원장 격언(M14 등 유효한 것)을 먼저 확인한다 (`stock-record` 스킬·메모리).

## 데이터 경로

| 항목 | 출처 |
|---|---|
| 종목 | `포트폴리오기록.xlsx` [보유종목] 상태=보유 + `종목분석_주문고려.xlsx` [요약] (판정 `보유로 이관`·`관심 해제` 제외) |
| 이익 전망 | `종목분석툴/_도구/성장률PER지도/history/<최신>.csv` 의 `eps_a`(내년)·`eps_b`(내후년) — 달력연도 환산·미장 Yahoo 수준 보정이 끝난 값 |
| 그 기록에 없는 미장 종목 | Nasdaq 연간 전망 + Yahoo 로 직접 조회 (메모에 `직접 조회`). 국장은 per_map.py 를 먼저 돌려야 잡힌다 |
| 종가 | 국장 = 다음 금융 정규장 `tradePrice` (네이버는 시간외 포함이라 쓰지 않는다) · 미장 = yfinance 직전 거래일 종가 (장중이면 전일) |

## 계산이 안 되는 것

- ETF·레버리지·펀드(SOXS·LYTE·CMCDI 등), 컨센서스가 없는 종목(서흥·테크윙 등).
- 이익이 거의 없는 종목(내후년 이익이 주가의 1% 미만 — HIMS·스노우플레이크). 이 방법은 이익이 있는 회사에만 맞는다.
