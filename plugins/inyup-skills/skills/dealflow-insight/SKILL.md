# 딜플로우 → 상장 투자 엣지

## 0. 이 시스템이 무엇인지 — 여기서 어긋나면 나머지는 의미가 없다

**섹터 정리는 엣지가 아니다.** "뷰티가 뜬다"는 시장도 안다. 이 시스템의 알파는 명사(섹터)가 아니라 **딜 문서 안의 숫자와 기울기** — 공시에도 애널리스트 리포트에도 없는 원가·마진·지불의사·확산속도 실측치다. 관찰에 숫자가 없으면 그것은 엣지가 아니라 인상이다.

**방향은 상향식이다.** "섹터 정리 → 종목 찾기"(하향식)로 쓰면 안 된다. 스크리너나 딥다이브가 종목을 먼저 올리고, 그 종목의 컨센서스 가정을 딜의 실측치로 검증하는 **상향식 대조**로만 쓴다. 이 스킬은 종목을 고르지 않는다.

**용도는 세 가지뿐이다.**

1. **컨센서스 검증·반박의 원료** — 딥다이브 7문 1번(변별점)·3번(선형 외삽)에 투입
2. **상장사 신사업의 진위 판별** — "AI 진출", "로봇 신사업" 주장을, 그 분야의 진짜 초기 트랙션이 어떤 모양인지와 대조해 테마주를 걸러낸다
3. **파괴·채널 전환의 조기경보** — 역방향 관찰(`역방향: true`)이 보유·후보 종목의 반대 논거인지 대조

**금지된 용도: 섹터 픽.** "이 섹터 딜이 많으니 이 섹터 주식을 산다"는 엣지가 아니라 컨센서스다.

**지리적 비대칭 원칙.** 같은 thesis라도 시장별 유효성이 다르다. 한국에서 안 되던 모델이 미국에서 성공하는 경우가 충분히 많다(AI 네오펌 — 미국은 성공 사례 다수 / TIC AI 롤업 — 국내에는 이 모델을 잘하는 상장사가 없어 미장·유럽 전용). **한국 관찰을 미국 종목에, 미국 관찰을 한국 종목에 기계적으로 이식하지 않는다.** 한국 딜은 "미국에서 진행 중인 변화가 한국에 도착하는 신호"로도 읽는다 — 이때 매매 대상은 오히려 미장 종목이다.

**기대치: 딜플로우 엣지는 매주 나오지 않는다.** 분기에 한두 번 정확히 겹치는 순간이 진짜이고, 나머지에 "해당 없음"을 출력하는 것이 이 시스템이 정직하다는 증거다. **억지 연결은 과적합이다** — 같은 섹터라는 이유만으로 관찰을 붙이면 이 시스템은 그 순간 가치를 잃는다.

## 1. 데이터 위치 — 스킬 폴더에 딜 데이터를 두지 않는다

`~/.claude/skills`는 **public GitHub 저장소**(`biy0613/my-skills`)를 가리키는 junction이고 세션 종료 시 자동 푸시된다. 회사 실명·딜 수치가 들어간 파일을 이 스킬 폴더에 만들면 그대로 공개된다. **관찰 DB와 맵은 프로젝트 폴더에만 둔다.**

데이터 폴더 해석 순서:

1. 현재 작업 디렉터리에 `observations.json`이 있으면 그것
2. 없으면 `C:\Users\biy06\OneDrive\바탕 화면\클로드실습\주식\종목분석툴\_프레임워크`
3. 그래도 없으면 `...\주식\종목분석툴` (2026-08-22 폴더 정리 이전 위치 — 하위 호환)
4. 그래도 없으면 사용자에게 폴더 경로를 묻는다. **임의로 다른 곳을 뒤지지 않는다.**

| 파일 | 역할 | 쓰기 |
|---|---|---|
| `observations.json` | 관찰 DB (정본) | refresh만 |
| `dealflow-insight-map-v1.md` | 시드 맵 — 테마 카드·역방향 신호의 서술본 | **읽기 전용** |
| `dealflow-sources.local.md` | 노션·시트 식별자, 미포착 IDM 명단, 수집 범위 | **읽기 전용** |
| `observations-table.md` | 사람이 읽는 표 (JSON에서 생성) | `render_table.py` |

**스킬 폴더에는 회사 실명·딜 수치·소스 식별자를 쓰지 않는다.** 참조 문서에 예시를 넣을 때도 `OBS-0xx`와 `__`로만 쓴다.

## 2. lookup — 대조 (주 기능)

입력: 종목명·티커 또는 주제. 출력: 관련 관찰 + 그 관찰이 이 종목의 **어떤 가정을 지지/반박하는지** 1~2문장. **없으면 "해당 없음".**

```bash
python scripts/lookup.py --market KR --q 펌텍코리아 --q 화장품용기 --q 색조
```

- `--market KR|US` — 지리적 비대칭 필터. 관찰마다 `적용가능` 라벨(예/주의/금지)이 붙는다. **생략하지 말 것** — 생략하면 미국 관찰이 한국 종목에 그대로 붙는다.
- `--q` — 검색어. 여러 번 준다. **티커만으로는 거의 안 걸린다**: 먼저 종목명·주력 제품·밸류체인 위치를 파악한 뒤 그 단어들로 조회한다(예: `005930`이 아니라 `반도체`·`메모리`·`HBM`).
- `--all` — 약한 일치까지 표시(기본은 임계값 이상만)
- `--json` — 기계 판독용

**출력 해석 규칙:**

- `적용가능: 금지` — 반례로만 언급하고 지지 근거로 쓰지 않는다
- `적용가능: 주의` — 시차·시장 차이를 반드시 문장에 적는다("미국 실측이며 국내 도착에는 시차가 있다")
- `신선도: 노후(18개월+)` — 그대로 쓰지 말고 "당시 관찰"임을 명시한다
- `신뢰도: 정성` — 숫자가 없는 관찰이다. **단독으로 변별점 근거가 될 수 없다.** Q4(파급 사슬 위치) 정도에만 쓴다

**응답 형식** (사용자에게 보이는 부분):

```
[종목명] 딜플로우 대조 — 해당 있음 2건 / 해당 없음

■ OBS-0xx · <출처> · <일자> · <유형> · <신뢰도> · 신선도 <라벨>
  실측치: (lookup 출력을 그대로)
  시장 유효성: <라벨> (적용가능: 예|주의|금지)
  → 지지/반박: 이 종목에 대한 컨센서스는 __를 가정하는데, 이 실측치는 그것을 (지지|반박)한다. 근거는 __.

내부 분석용 · 투자 권유 아님
```

**"해당 없음"을 쓰는 것을 주저하지 마라.** 스크립트 결과가 비었는데 억지로 테마를 연결해 문장을 만들면 그 순간 시스템이 망가진다. 결과가 비면 이렇게만 쓴다: `딜플로우 엣지: 해당 없음 — 관찰 DB에 이 종목의 밸류체인·수요 구조와 겹치는 실측치가 없다.`

지지/반박 문장을 쓸 수 없으면(= 컨센서스가 무슨 가정을 하는지 모르면) 관찰만 제시하고 **"대조 대상 가정 미확인"**이라고 적는다. 지어내지 않는다.

## 3. refresh — 갱신 (분기 1회 또는 요청 시)

절차·명령·함정은 `references/refresh.md`를 읽고 수행한다. 요약:

1. 소스 접근 모드 판정 (모드 A 소스 직결 / 모드 B 시드+export 파일)
2. 신규 IDM·시트 행 수집 → 관찰 추출 (수집 범위 기본값은 `dealflow-sources.local.md`에 정의)
3. `observations.json`을 vN+1로 갱신
4. **변경분만** 보고: 신규 관찰 n건 / 승격된 테마 / 시장 유효성이 바뀐 관찰

**새 테마는 관찰 3건 이상 반복될 때만 카드로 승격한다.** 1~2건은 관찰로만 쌓아두고 테마로 부르지 않는다.

**수집 범위를 기본값(1인 작성분) 밖으로 넓힐지는 반드시 먼저 물어본다.** 묻지 않고 확장하면 맵의 성격 자체가 "내 딜플로우의 엣지"에서 "하우스 전체 요약"으로 바뀐다. 기본값과 확장 대상은 로컬 식별자 파일에 있다.

## 4. 보안 — 예외 없음

- **노션은 읽기 전용.** 어떤 페이지도 수정·생성·이동·삭제하지 않는다. 구글 시트도 읽기만 한다. 쓰기 계열 MCP 도구(`notion-create-*`, `notion-update-*`, `notion-move-*`, 드라이브 `create_file` 등)는 이 스킬에서 **호출하지 않는다.**
- 딜 데이터(회사 실명·수치)는 프로젝트 폴더 안에만 저장한다. 슬랙·메일 등 외부 채널로 **딜 원문·회사 실명을 내보내지 않는다.** 내보낼 수 있는 것은 종목 대조 결과(관찰의 함의)뿐이고, 그때도 회사명 대신 "비상장 딜 관찰"로 익명화한다.
- 모든 산출물 말미에 **"내부 분석용, 투자 권유 아님"**을 적는다.

## 5. 품질 게이트

- **문서에 없는 내용을 지어내지 않는다.** 접근 불가·판단 불가는 그대로 보고한다. 관찰의 `실측치` 필드는 딜 문서에 실제 기재된 것만 담긴다 — 여기에 없는 숫자를 만들지 않는다.
- 모호한 부분은 임의로 정하지 말고 사용자에게 묻는다.
- 상장 매핑은 전부 **후보**다. `검증 필요` 라벨을 지우지 않는다 — 스크리너 필수컷과 딥다이브 7문을 통과해야 매수 후보가 된다.
