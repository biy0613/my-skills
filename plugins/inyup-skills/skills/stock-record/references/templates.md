# 단계별 입력 템플릿

채팅에 그대로 띄우고 사용자가 채우게 한다. **필드 이름은 바꾸지 않는다** — 그대로
payload의 `데이터` 키로 쓰인다.

---

## ① 진입 (단계: `진입`)

### 1단계 — 하드게이트 먼저 (O/X)

```
1. 실적 발표를 1회 이상 통과하며 관찰했는가 (최소 1개월)   [ ]
2. 이 종목을 한 문장으로 설명할 수 있는가                  [ ]
3. 반대 논지를 2개 이상 적을 수 있는가                     [ ]
4. 손절 조건을 가격 + 사실 양쪽으로 숫자화했는가            [ ]
5. 포지션 크기가 사전 규칙 내인가                          [ ]
6. 사는 이유가 급등·뉴스·손실 복구가 아닌가 (24h 쿨다운)    [ ]
```

X가 하나라도 나오면 **먼저 그 사실을 말하고** 진행 여부를 확인한다.
진행한다면 `규칙 이탈 여부`에 어떤 게이트를 왜 넘겼는지 적는다.

### 2단계 — 서술 항목

| 필드 | 물어볼 말 |
|---|---|
| 기록일 | (오늘 날짜 자동) |
| 하드게이트 통과 (O/6) | 예: `5/6` |
| 미통과 항목 | X가 난 번호와 이유 |
| 규칙 이탈 여부 | 없으면 `없음` |
| 핵심 논지 (한 문장) | **한 문장으로.** 두 문장이 되면 아직 정리가 안 된 것 |
| 가정 1 / 가정 2 / 가정 3 | 논지를 지탱하는 가정 |
| 가정 N — 확인 시점·방법 | 언제 무엇으로 확인되나. 확인 불가능하면 가정이 아니라 희망 |
| 반대 논지 (2개 이상) | 파는 쪽 논리를 **가장 설득력 있게** |
| 가장 반박하기 어려운 것 | 위 중 하나 |
| 컨센서스와 내 견해 차이 | 시장이 믿는 것 vs 내가 다르게 보는 것. **비면 초과수익 근거가 없다** |
| 지금 가격이 이미 반영한 것 | 현재 밸류에이션이 암시하는 성장률·마진 |
| 펀더멘탈 | 매출·이익 구조, 현금흐름, 부채, 희석 |
| 법률·규제 리스크 | 진행 사안, 최악 손실 규모, 일정 |
| 수급 | 외인·기관 지분율, 공매도 잔고, 내부자 매매 |
| 카탈리스트 | 이벤트 + 예상 시점 |
| 시간 지평 | 논지 검증 소요 개월 vs 버틸 수 있는 개월 |
| 정보원 | 전담 X 계정 / 1차 소스 |
| 매수 시 감정 상태 | 평온 / 조급 / 복구심리 / FOMO |
| 목표 비중 / 최대 허용 손실 | 총자산 대비 % + 원화 손실 상한 |
| 분할·추가매수 규칙 | **지금 정하지 않으면 하락 중에 반드시 물타기로 간다** |
| 손절 조건 — 사실 | 무엇이 확인되면 논지가 죽나 |
| 손절 조건 — 가격 | 숫자 |
| 손절하지 않는 경우 | 예: 시장 전체 조정이고 사실 기준 미발생 |
| 익절 조건 — 사실 | 논지가 완성되는 사건 |
| 익절 조건 — 가격 | 목표가 + 근거 |

마스터에 함께 넣을 것: `수량` `평균단가` `진입일` `목표비중` `손절선` `익절목표`
(+ 새 종목이면 `티커` `시장` `통화`)

---

## ② 보유 점검 (단계: `보유점검`)

분기 1회 + 이벤트(실적 / 논지 관련 중대 뉴스 / −20% / +50% / 비중 상한 초과) 발생 시.

| 필드 | 값 |
|---|---|
| 점검일 | |
| 점검 요약 | 진입 이후 무엇이 바뀌었나 |
| 가정1 / 가정2 / 가정3 | `확인` / `미확인` / `반증` |
| 논지 드리프트 | `같음` / `다름` — 다르면 **새 종목을 산 것**이므로 진입 게이트 재작성 |
| 리셋 질문 | `산다` / `안 산다` — "오늘 안 갖고 있다면 이 가격에 살 것인가" |
| 손절선 갱신 | **강화(위로)만 허용. 완화 금지** |
| 현재 비중 | |
| 결론 | `유지` / `비중조절` / `회수검토` / `전량매도` |

반증이 1개 이상이면 회수 게이트로 넘어갈지 묻는다.

---

## ③ 회수 (단계: `회수`)

A 보류게이트 7 / B 강제트리거 6을 먼저 판정한 뒤 기록한다.

| 필드 | 값 |
|---|---|
| 매도일 / 매도 단가 / 매도 수량 | |
| 실현 손익(원) / 실현 수익률 / 보유 기간 | |
| A 보류게이트 X 개수 | |
| B 강제트리거 O 개수 | |
| 매도 유형 | `①논지훼손` `②목표달성` `③교체` `④리스크관리` `⑤현금필요` **하나만** |
| 유형 근거 — 요건이 성립하는가 | 그 유형의 요건을 실제로 만족하는지 |
| 계획대로였나 | `계획대로` / `규칙 이탈` |
| 이탈 내용 | 무엇을 어떻게 벗어났나 |

## ③-E 홀드 (단계: `홀드`)

**B 트리거가 켜졌는데 팔지 않기로 한 경우. 반드시 남긴다.**

| 필드 | 값 |
|---|---|
| 날짜 | |
| 보유 이유 | 그래도 들고 가기로 한 근거 |
| 켜진 B 트리거 | 번호 |
| 구분 | `규칙 이탈` / `사전 정의된 예외` |
| 재점검 기한 | 최대 1개월 |

---

## ④ 사후 추적 (단계: `사후추적`)

매도 후 D+90 / D+180 / D+365. 매도가 끝이 아니라 여기까지가 한 사이클이다.

| 필드 | 값 |
|---|---|
| 시점 | `D+90` / `D+180` / `D+365` |
| 날짜 / 주가 / 매도가 대비 | |
| 판단 평가 | 내 매도 판단은 옳았나 |
| 과정/결과 4분면 | `과정O·결과O` / `과정O·결과X` / `과정X·결과O(경고)` / `과정X·결과X` |
| 배운 것 | 1~2줄 |
| 다음 종목에 적용할 규칙 변경 | |

**과정O·결과X는 규칙을 바꾸지 않는다** (운이 나빴을 뿐).
**과정X·결과O가 경고다** — 여기서 규칙 이탈이 정당화되기 시작한다.
