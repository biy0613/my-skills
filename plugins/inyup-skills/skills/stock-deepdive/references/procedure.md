# 7문 작성 지침 — 각 문항에서 실제로 무엇을 조회하고 무엇을 쓰는가

문항당 2~4문장. 모든 근거에 **출처·조회일** 병기. 답이 안 서면 비워두고 **"판단 불가"**로 표기한다 — 추정으로 채우지 않는다.

---

## 1. 컨센서스와 나의 변별점 (필수)

**먼저 주가가 내포한 기대를 문서화한다.** 이걸 건너뛰고 "이 회사는 좋다"를 쓰면 그건 변별점이 아니라 소개다.

조회할 것:

| 항목 | 국장 | 미장 |
|---|---|---|
| 12M Fwd PER | 네이버 `integration` API의 `cnsPer` | yfinance `forwardPE` |
| FY1·FY2 컨센서스(매출·영업이익·EPS) | WISEreport FY 추정 | yfinance / 웹 리서치 |
| 최근 분기 실적 | FnGuide 분기 손익 | `get_financial_statement` (quarterly) |

이 숫자들로 한 문장을 만든다:

> "현재 주가는 12M Fwd PER __배(출처, 조회일). 컨센서스는 FY+1 매출 __% 성장과 영업이익률 __%를 가정하고 있다."

**그다음 내가 어느 숫자에서, 왜 다르게 보는지 한 문장.** 이 문장이 안 써지면 엣지가 없는 것이고, 그러면 결론은 PASS다. 어설픈 문장으로 채우지 말 것 — "성장성이 좋아 보인다"는 변별점이 아니다. 변별점은 **특정 숫자에 대한 반대 견해**다.

컨센서스 데이터가 아예 없는 종목(커버리지 없음)이면 "시장이 가정하는 바를 특정할 수 없음"이라고 쓴다. 이 경우 1번은 성립하지 않으므로 **결론은 PASS**다. 컨센서스가 없다는 것은 반박할 대상이 없다는 뜻이다.

## 2. 촉매와 시점 (필수)

시장이 내 견해로 수렴하게 될 계기와 예상 시점을 쓴다. **촉매 없는 저평가는 가치 함정이다.**

촉매 후보와 확인 경로:

- **실적 발표** — 국장: DART 공시 일정 / 미장: yfinance `earningsDate`. 다음 발표일을 실제로 확인해 적는다
- **수주·계약 공시** — DART `search_disclosures` / SEC 8-K
- **신제품·양산 시점** — IR 자료, 웹 검색
- **정책·규제** — 인허가 일정, 제도 시행일
- **행동주의·지배구조** — 지분 공시, 주총 안건

**2분기 내 촉매가 특정되지 않으면 감점한다.** "언젠가 실적이 좋아지면"은 촉매가 아니다. 날짜나 분기가 붙어야 촉매다.

## 3. 추정치의 선형 외삽

애널리스트 추정은 관성이 있어 구조 변화를 점진적으로만 반영한다. **컨센서스가 놓치고 있는 비선형이 있는가.**

찾을 것:

- **고정비 레버리지** — 매출 증가율 대비 영업이익 증가율이 최근 분기에 점프했는가. 증분 마진(ΔOP/ΔRev)을 직접 계산한다
- **가격 인상** — ASP 상승이 실적에 반영되기 시작했는가
- **믹스 개선** — 고마진 제품 비중 변화(국장은 FnGuide 매출구성, 미장은 세그먼트 공시)

**최근 분기 실적 모멘텀과 컨센서스 기울기를 비교한다.** 실제 분기 성장률이 컨센서스가 가정한 연간 성장률보다 뚜렷이 높으면 상향 여지가 있다는 뜻이고, 그 반대면 하향 위험이다.

## 4. 파급 사슬 위치

이 종목은 해당 테마의 **몇 차 수혜인가**(예: AI → 1차 HBM → 2차 전력기기 → 3차 냉각·전선). 1차 수혜주의 실적·수주에서 이 종목의 미래가 읽히는가. **시장은 몇 차까지 반영했는가.**

1차 수혜주의 최근 실적·수주 잔고를 실제로 확인하고, 이 종목의 매출 인식이 그것보다 몇 분기 뒤에 오는지 쓴다. 시간 차가 없으면 "이미 같이 반영됨"이고, 그건 엣지가 아니다.

## 5. 딜플로우 엣지

`SKILL.md` §3의 규칙을 따른다. 요약하면 — **미시 실측치 대조만 하고, 섹터 일치는 엣지가 아니며, 지리적 비대칭을 지키고, 없으면 "해당 없음"이라고 쓴다.**

출력 형식:

```
5. 딜플로우 엣지 — 해당 있음
OBS-0xx (<출처>, <일자>, <유형>, <신뢰도>, 적용가능 <라벨>)
실측치: (lookup 출력을 그대로 인용)
→ 이 종목의 컨센서스는 __를 가정하나(1번 참조), 이 실측치는 __이므로
   그 가정을 (지지|반박)한다.
```

이 스킬 문서에는 딜 회사명·수치를 적지 않는다(public 저장소). 실제 값은 lookup 출력에서 읽어 산출물에만 쓴다.

## 6. 매도자 구조

**왜 나는 지금 이걸 싸게 살 수 있는가.**

- **비정보성 매도**(패시브 리밸런싱, 디그로싱, 펀드 환매, 수급 이탈) → **최고의 거래 상대다**
- **정보성 매도**(대주주·내부자 매도, 핵심 고객 이탈 인지자) → **내가 모르는 것이 있다는 뜻이므로 중단한다**

확인 경로:

| 확인 대상 | 국장 | 미장 |
|---|---|---|
| 내부자·대주주 매도 | DART `get_major_stock`(대량보유 상황보고), `get_executive_stock`(임원·주요주주 소유보고) | SEC Form 4 (EDGAR) |
| 기관·외국인 수급 | 네이버 `trend` API | 13F, `get_holder_info` |
| 패시브 이벤트 | MSCI/FTSE 정기변경 일정 웹 검색 | 지수 리밸런싱 일정 |

**내부자 매도가 클러스터로 나오면 그 자체로 중단 사유다.** 이유를 상상해서 변호하지 않는다.

## 7. 사전 부검 + 무효화 조건 (필수)

**먼저 이 투자가 실패한다면 그 이유의 최강 버전(스틸맨)을 쓴다.** 약한 반대 논거를 세워 이기는 것은 자기기만이다. 5번에서 나온 역방향 관찰(`역방향: true`)이 있으면 여기에 반드시 반영한다.

**그다음 "이 지표가 이렇게 되면 내 thesis는 죽은 것"을 관찰 가능한 숫자 1~2개로 정한다.**

좋은 킬 스위치의 조건 — ① 숫자다 ② 공개 데이터로 확인 가능하다 ③ 확인 주기가 있다.

- 좋음: "12M 선행 영업이익 컨센서스가 3개월 내 −5% 이상 하향" / "내부자 매도 3건 이상 클러스터" / "핵심 고객 이탈 공시"
- 나쁨: "업황이 나빠지면" / "경쟁이 심해지면" — 관찰 시점을 특정할 수 없다

**무효화 조건 없는 매수는 금지.** 이 문항이 비면 결론은 PASS다.

---

## 필수 문항 판정 절차 (기계적으로 적용)

카드를 쓰기 전에 이 세 줄을 먼저 채운다.

```
1번 변별점 성립?  예 / 아니오 — (아니오면 사유)
2번 촉매 성립?    예 / 아니오 — (2분기 내 특정 가능한가)
7번 무효화 성립?  예 / 아니오 — (관찰 가능한 숫자인가)
```

하나라도 `아니오`면 **결론 = PASS(엣지 없음)**. 나머지 문항이 좋아도 예외 없다. PASS 카드에도 7문 내용은 남긴다 — 나중에 촉매가 생겼을 때 다시 볼 자산이 된다.

## 흔한 실패

- **컨센서스를 문서화하지 않고 변별점을 쓴다.** 무엇과 다른지 없이 "다르다"고 쓰는 것 — 가장 흔하고 가장 치명적이다.
- **기억으로 PER·성장률을 채운다.** 반드시 조회하고 조회일을 적는다.
- **촉매에 날짜가 없다.** "실적 개선 시"는 촉매가 아니다.
- **5번에서 섹터가 겹친다고 엣지라고 쓴다.** 미시 실측치가 특정 가정을 건드려야 엣지다.
- **PASS를 피하려고 문항을 억지로 채운다.** PASS 비율이 낮으면 시스템이 고장 난 것이다.
- **조회 실패를 부정적 판정으로 처리한다.** "확인 불가"와 "미충족"은 다르다.
