# 종목 딥다이브 — 변별적 관점 생성기

초과수익 = **① 컨센서스와 다른 근거 있는 견해 + ② 시장이 내 견해로 수렴하게 만들 촉매.** 남들과 같은 분석(Part A)은 공격이 아니라 방어(탈락 심사)이고, 혜안은 Part B의 질문에서 나온다.

**PASS는 실패가 아니라 시스템의 절반이다.** 후보 20개 중 변별적 관점이 서는 것은 보통 2~3개. 투자에는 스트라이크 콜이 없다 — 엣지가 안 보이는 공은 보낸다. 억지로 매수 후보를 만들어내면 이 스킬은 그냥 종목 소개서가 된다.

## 입력

- 필수: 종목명 또는 티커
- 선택: 스크리너 근거 요약(수급·리셋·ETF·스코어), 관심 이유 한 줄

## 실행 순서

### 0. 시장 판별 → 데이터 소스 분기

| 입력 형태 | 판정 |
|---|---|
| 6자리 숫자(`005930`), `.KS`/`.KQ` 접미사 | 국장 |
| 영문 1~5자 티커(`NVDA`) | 미장 |
| 한글 종목명 | **국내 상장 여부를 먼저 확인한다.** "테슬라"·"엔비디아"처럼 미장 종목의 한글 표기일 수 있다 |
| 양쪽에 유사 이름 존재 | 사용자에게 확인. 추측하지 않는다 |

판별 후 `references/data-sources.md`의 해당 시장 경로를 읽고 수치를 조회한다. **모든 수치에 출처·조회일을 병기한다.**

### 1. Part A — 방어 심사 (목적: 탈락)

통과시키러 보는 게 아니라 **떨어뜨리러** 보는 단계다. 하나라도 설명이 안 되면 여기서 끝내고 사유를 보고한다. 7문으로 넘어가지 않는다.

| # | 체크 | 탈락 기준 |
|---|---|---|
| A1 | 수익 구조 한 문장 | "이 회사는 __에게 __를 팔아 __로 돈을 번다"가 한 문장으로 안 써지면 탈락 |
| A2 | 가격 결정력 | 원가 상승을 고객에게 전가한 이력이 없고 마진이 구조적으로 눌리는 사업이면 탈락 |
| A3 | 이익의 품질 | 영업이익 대비 영업현금흐름이 만성적으로 낮으면(이익이 현금이 안 됨) 탈락 |
| A4 | 성장의 원천 | 성장이 P(가격)인지 Q(물량)인지 구분이 안 되거나 일회성 수주 착시면 탈락 |
| A5 | 생존 리스크 | 단일 고객 의존 과다 · 규제 절벽 · 상시 희석(CB/BW 남발)이면 탈락 |

**조회 실패는 탈락이 아니다.** A3를 판정할 현금흐름을 못 받았으면 "탈락"이 아니라 "판정 불가"이고, 그 사실을 카드에 남긴다. 이 둘을 뭉치면 데이터 문제가 실적 문제로 둔갑한다.

### 2. 피어 비교표 — 자동 실행 (7문 진입 전 필수)

Part A를 통과하면 **묻지 말고 바로 돌린다.** 사용자가 요청하지 않아도 실행한다.

```bash
python scripts/peers.py --target <티커> --peers <피어1,피어2,...>
```

```bash
python scripts/peers.py --target 192820 --peers 161890,251970,352480
```

국장은 6자리 코드를 그대로 주면 `.KS` → `.KQ` 순으로 자동 탐색한다.

**피어는 섹터 라벨이 아니라 사업 모델로 고른다.** 3~8곳, 그중 흑자 기업이 최소 2곳 들어가야 중앙값이 의미를 갖는다. 선정 규칙·함정·실제 사례는 `references/peer-groups.md`를 읽는다.

산출된 표는 **7문 1번(변별점)의 입력**이다. 배수가 피어 대비 어디인지 모르면 "시장이 이 종목에 무엇을 기대하는가"를 쓸 수 없다. 표는 산출물에 그대로 싣고, 최소한 이 두 줄을 1번에 반영한다:

- 기준 종목의 PER(F)·EV/EBITDA가 피어 중앙값의 몇 배인가
- 그 배수 차이를 **성장률·마진 차이가 설명하는가, 설명하지 못하는가**

**배수만으로 싸다/비싸다를 결론내지 않는다.** 피어보다 싼 데는 대개 이유가 있고, 그 이유가 일시적인지 구조적인지가 7문 전체의 질문이다.

**실행 실패 시**: 스크립트가 죽거나 피어가 전부 `조회실패`면 "피어 비교 불가"로 표기하고 7문을 진행한다. 숫자를 기억으로 채우지 않는다.

### 3. Part B — 한 발 앞선 7문

문항당 2~4문장. 작성 지침과 각 문항에서 실제로 조회할 수치는 `references/procedure.md`를 읽는다.

1. **컨센서스와 나의 변별점** — 주가가 내포한 기대를 먼저 역산해 문서화한 뒤, 내가 **어느 숫자에서** 다르게 보는지 한 문장
2. **촉매와 시점** — 시장이 내 견해로 수렴할 계기와 예상 시점. 2분기 내 촉매가 특정되지 않으면 감점
3. **추정치의 선형 외삽** — 컨센서스가 놓친 비선형(고정비 레버리지·가격 인상·믹스 개선)이 있는가
4. **파급 사슬 위치** — 몇 차 수혜인가, 시장은 몇 차까지 반영했는가
5. **딜플로우 엣지** — 아래 §3 규칙대로 `dealflow-insight`를 호출
6. **매도자 구조** — 지금 싸게 살 수 있는 이유. 매도 주체가 비정보성이면 최고의 거래 상대, 정보성이면 중단
7. **사전 부검 + 무효화 조건** — 실패 이유의 최강 버전(스틸맨) + 관찰 가능한 킬 스위치 1~2개

**필수 문항: 1(변별점) · 2(촉매) · 7(무효화).** 셋 중 하나라도 성립하지 않으면 **결론은 자동으로 PASS.** 나머지 문항이 아무리 좋아도 예외 없다. "무효화 조건 없는 매수는 금지"가 이 규칙의 이유다.

### 4. 5번 문항 — 딜플로우 엣지 (이 스킬에서 가장 오용되기 쉬운 부분)

`dealflow-insight` 스킬의 lookup을 쓴다.

```bash
python C:/Users/biy06/.claude/skills/dealflow-insight/scripts/lookup.py --market KR --q <종목명> --q <주력제품> --q <밸류체인키워드>
```

**섹터 일치 확인용이 아니라 미시 데이터 대조용이다.** 맵·DB에 기록된 원가·마진·지불의사·확산속도 실측치가 이 종목의 **컨센서스 가정을 지지하는지 반박하는지**를 쓴다. "같은 섹터의 딜이 있었다"는 것 자체는 엣지가 아니다.

- **지리적 비대칭 원칙을 지킨다.** 같은 thesis라도 시장별 유효성이 다르다 — 한국에서 안 되던 모델이 미국에서 성공하는 경우가 많다(AI 네오펌). 한국 관찰을 미국 종목에, 미국 관찰을 한국 종목에 기계적으로 이식하지 않는다. lookup이 출력하는 `적용가능` 라벨(예/주의/금지)을 그대로 따른다.
- **`신뢰도: 정성` 관찰로 1번(변별점)을 만들지 않는다.** 숫자 없는 관찰은 4번(파급 사슬)까지가 한계다.
- **결과가 비면 "해당 없음"으로 적고 넘어간다.** 억지 연결은 과적합이다. 해당 없음은 정상 출력이며, 이 문항 하나가 비었다고 결론이 나빠지지 않는다.
- **맵·DB가 폴더에 없으면 5번을 "대조 필요"로 표기**하고 나머지를 진행한다.
- **맵·DB는 읽기 전용.** 수정하지 않는다. 맵의 원천(노션·구글시트)에 접근할 필요도 없다 — **이 스킬의 데이터 소스는 공개 시장 데이터와 웹 리서치뿐이다.**

### 5. Part C — 판정 카드 1장

| 항목 | 내용 |
|---|---|
| 변별적 관점 | (한 문장) |
| 촉매 / 예상 시점 | |
| 피어 대비 밸류에이션 | PER(F) __배 = 피어 중앙값의 __배 / 그 차이를 성장·마진이 설명하는가 |
| 상방 : 하방 | (대략적 기대수익 대비 리스크) |
| 무효화 조건 (킬 스위치) | (관찰 가능한 지표 1~2개) |
| 엣지의 원천 | 정보(수급·딜플로우) / 분석(2차 사고) / 행동(시간 재정거래) 중 무엇인지 |
| 결론 | 매수 후보 / 관찰 / **PASS(엣지 없음)** |
| 스크리너 근거 요약 | 수급·리셋·ETF·스코어 (있을 때만) |

산출물은 대화에 마크다운으로 낸다. 사용자가 문서를 원하면 `research-report-design-system` 스킬을 로드해 HTML로 만들고, 파일은 프로젝트 폴더에 `deepdive_<종목>_<YYYYMMDD>.md`로 저장한다.

## 절대 원칙

**근거 없는 숫자를 쓰지 않는다.** 조회 실패·판단 불가는 그대로 표기한다. 이 스킬의 산출물은 나중에 매매 판단의 근거로 다시 읽히므로, 어느 숫자가 진짜인지 구분되지 않으면 문서 전체가 쓸모없어진다. 기억으로 PER·성장률을 채우는 것이 가장 흔한 실패다.

**2차 사고의 과적합을 경계한다.** 너무 꼬면 1차 결론이 맞는 경우를 놓친다. 최고의 변별점은 대개 "단순한데 남들이 보기 싫어하는 것"이다.

**최종 판정은 사람의 몫이다.** 7문 초안과 카드까지 자동 생성하되, 매수 후보/관찰/PASS의 확정은 사용자에게 넘긴다.

**투자 조언으로 흐르지 않는다.** 산출물 말미에 투자 권유가 아님을 명시한다.
