# 리포트 산출물 규격

`research-report-design-system` 스킬을 로드해 HTML로 출력한다. 아래는 이 스크리너 고유의 **내용 요건**이다.

## 구조

| 섹션 | 내용 |
|---|---|
| 커버 | 제목 · 메타 테이블(기준일·측정구간·데이터소스·차단소스) · KPI 4개(유니버스/후보/통과/★리셋) · Key Takeaway 콜아웃 |
| Ⅰ. 데이터 소스 제약 | **KRX 차단 사실과 대체 경로, 그로 인한 계산 편차를 표로.** 이걸 빼면 독자가 숫자를 잘못 신뢰한다 |
| Ⅱ. 스크리닝 퍼널 | 단계별 잔존/제거 종목 수와 판정 방식. `screen_result.json`의 `funnel` |
| Ⅲ. 요약 테이블 | 통과 종목 전체 (아래 컬럼 규격) |
| Ⅳ. 개별 카드 | 상위 7종목 (아래 필드 규격) |
| Ⅴ. 노이즈 검증 | E-1 단일일 집중 · E-2 패시브 · E-3 숏커버 · E-4 외국계 창구 · **조정 원인 규명** |
| Ⅵ. 탈락했지만 아까운 종목 | 3개 + 통과한 조건 / 탈락 사유 / 판단 |
| Ⅶ. 데이터 검증 로그 | 아래 4개 하위 표 |
| 면책 | 투자 권유가 아님을 명시 |

## Ⅲ. 요약 테이블 컬럼

종목명·코드 / 시총 / 섹터 / 외국인 순매수액 / 순매수÷시총(%) / 순매수 일수 / 외국인 지분율 변화(%p) / 직전분기 OP YoY / 12M Fwd PER / 낙폭 / 총점 / 태그

- 순매수÷시총 옆에 **구간 기준선을 괄호로** 병기하면 강도가 한눈에 보인다: `5.69% (0.7)`
- 태그: `★리셋` `패시브` `숏커버` `단일일 N%` `PER예외` `조정 없음`
- 임계 통과 수치(YoY ±50%↑, 낙폭 −30%↑, PER 30↑ 등)는 accent 컬러 처리

## Ⅳ. 개별 카드 필드 (각 300자 내외)

1. **밸류체인 포지션** — 한 줄. "반도체 관련주" 금지. 무엇을 만들어 누구에게 파는지, 그 밸류체인에서 몇 번째 위치인지.
2. **무엇을 파는 회사인가 / 매출 구성** — `rev_mix`의 실제 비중 수치를 쓴다.
3. **외국인이 지금 사는 이유 (가설)** — 근거 있는 추정. **`추정` / `일부 확인` 칩으로 확신도를 구분**한다. 언론으로 확인된 것과 데이터에서 추론한 것을 섞지 않는다.
4. **실적 근거 숫자 3개** — 분기 OP와 YoY, 영업활동현금흐름 대 영업이익 비율, FY 컨센서스 성장률 중에서.
5. **리스크 2개** — 일반론 금지. 이 종목 데이터에서 실제로 보이는 약점(현금전환율 저조, 컨센 상향폭 미미, 분기 실적 우하향 등).
6. **추가 확인 2개** — 사용자가 다음에 무엇을 열어봐야 하는지. 구체적 문서·일정·항목으로.

카드 상단에 시총·종가·52주고·Fwd PER·PEG·목표주가를 mono 폰트 한 줄로 넣으면 스캔이 빠르다.

## Ⅴ. 조정 원인 규명 (필수)

요청 규정상 **실적 쇼크가 원인이면 후보에서 제외**해야 하므로 근거를 명시한다. 판정 논리:

- 컨센서스가 상향 중이면 실적 쇼크가 아니다 → `cons_chg` 값을 근거로 제시
- 조정이 개별 종목이 아니라 동시다발이면 시장 요인 → **해당 기간 지수 급락일을 웹 검색해 사건을 특정**한다
- 두 조건이 모두 성립하면 ★밸류에이션 리셋

## Ⅶ. 검증 로그 하위 표

1. **사용 함수·파라미터·조회일** — 소스별로 호출 형태와 결과 건수
2. **조회 실패 및 결측** — `확인불가` 항목 전부. 왜 못 했는지까지
3. **소스 간 수치 대조** — 최소 2건. `screen_result.json`의 `cross_check` + 언론 대조
4. **계산 정의** — 순매수금액·집중도·12M Fwd 가중치·낙폭의 산식

## 밸류에이션 예외 서술

`fwdPER > 30`인데 PEG로 통과한 종목은 **정당화 근거를 반드시 쓴다.** 형식:

> FY0E EPS → FY1E EPS 증가율 X%가 추정돼 있고, 12M 선행 영업이익 컨센서스가 3개월간 Y% 상향됐다. 현재 PER은 실적 J커브 초입의 저점 이익을 분모로 쓴 결과이며 FY1 기준으로는 약 Z배로 수렴한다. 다만 이 논리는 FY1E 추정치 실현을 전제한다.

반대로 PEG가 높은데 PER로 통과한 종목(저성장·저평가)도 그 사실을 적는다 — 성장주 논리로 읽히면 안 되기 때문이다.

## 톤

- 모든 숫자에 출처와 조회일을 병기
- `확인불가`는 숨기지 말고 명시적으로 표기
- 매수·매도 권유 표현을 쓰지 않는다. 관측된 사실과 그에 대한 해석을 구분해 서술한다
- 통과 종목 수가 요청 수에 미달하면 그 사실과 이유를 커버나 Ⅱ장에 적는다
