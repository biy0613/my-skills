# 투자밋업 보고서 & 거절 메일 스킬

회사 IR과 대표명·밋업일시·평가점수(1~5)·밋업 사진을 폴더에 넣고 요청하면,
스타트업플러스 투자밋업 보고서(PDF)와 투자 거절 메일(Word, 회사별 1개)을 생성합니다.

- 입력: 연결 폴더에 IR PDF + `회사명1.png`·`회사명2.png`, 채팅으로 회사명/일시/대표/점수
- 출력: `투자밋업 보고서(회사명).pdf`, `투자 거절 메일(회사명).docx`
- 어투·길이·템플릿은 패스트벤처스 박인엽의 기존 방식을 그대로 반영
- 다른 투자사가 쓰려면 scripts/build_report.py의 FIXED(고정필드)만 수정

필요 환경: Python(python-docx, PyMuPDF, Pillow), LibreOffice(soffice)
