# 투자밋업 보고서 & 투자 거절 메일 생성

회사 IR을 읽고 견본 어투의 검토 의견을 작성해 **투자밋업 보고서 PDF**를 만들고, 기본 동작으로 **투자 거절 메일 Word**(회사별 1개)를 생성한다. 어투·길이·템플릿·톤은 패스트벤처스 박인엽의 기존 방식을 그대로 따른다.

## 입력 (사용자 제공)
- **연결 폴더**에: 회사 IR PDF(또는 소개자료), 밋업 사진 2장을 `회사명1.png`·`회사명2.png`로 저장.
- **채팅**으로: 회사명, 밋업일시, 대표명, 평가점수(1~5).
- 점수→투자의향: 5=매우높음 / 4=높음 / 3=보통 / 2=낮음 / 1=매우낮음.

## 작업 순서
1. **입력 확인** — 폴더에서 IR PDF와 `회사명1/2.png`를 찾는다. 사진이 채팅에 붙여넣기만 됐다면 파일로 접근 불가하므로 "연결 폴더에 `회사명1/2.png`로 저장"을 요청한다. (사진 처리 상세: `references/report-spec.md`)
2. **IR 정독** — `fitz`(PyMuPDF)/`pypdf`로 텍스트 추출. 이미지로만 된 슬라이드면 페이지를 PNG로 렌더해 Read로 직접 본다(컨택트시트로 구조 파악 후 핵심 페이지 정독). 사업 아이템·차별점·시장·기술/실적·재무를 파악한다.
3. **검토 의견 작성** — 7개 항목(아이템 개요·차별화 특징·시장 적합성·기술 차별성·재무 현황·긍정적 검토의견·부정적 검토의견)을 **견본 어투**로, **보고서 상 각 2줄(약 65~70자)**로 작성한다. 점수가 낮을수록 부정 의견이 결론을 뒷받침하도록. 어투·예시는 `references/tone-and-examples.md`.
4. **보고서 생성** — data JSON을 만들어 `python3 scripts/build_report.py data.json "투자밋업 보고서(회사명).docx"` 실행 → 같은 폴더에 PDF 생성(고정필드 내장, 사진 자동 맞춤). data 스키마·고정필드는 `references/report-spec.md`.
5. **검증** — PDF를 렌더해 (a) 1페이지, (b) 7개 항목 각 2줄, (c) 투자의향 ■가 점수와 일치, (d) 사진 2장 삽입을 확인한다.
6. **거절 메일 생성(기본 동작)** — 회사별 거절 메일 입력 dict(`company/ceo/story/strength/negative`)를 만들어 `python3 scripts/make_rejection_email.py email.json <출력폴더>` 실행 → `투자 거절 메일(회사명).docx`. 템플릿 원문·치환 규칙·강점1·단점2~3 작성법은 `references/email-template.md`. **점수와 무관하게 항상 거절 메일을 생성**한다(사용자가 생략/변경을 명시하면 제외).
7. **저장·제시** — PDF와 메일 Word를 연결 폴더에 저장하고 present_files로 제시. 무엇을 만들었는지 1~2문장으로만 요약한다.

## 반드시 지킬 것
- 7개 검토 항목은 **각 2줄**. 길면 사진 포함 시 2페이지로 넘친다.
- 고정 필드(투자기관명·담당자·관심분야·보유펀드·▣창업투자회사·온라인 미팅·계좌)는 `build_report.py`에 내장 — 회사마다 바꾸지 않는다.
- 가운데 라벨(시장 적합성 등)은 생성기가 단어 단위로 줄바꿈하므로 텍스트 내용만 신경 쓴다.
- 작업 폴더 FS가 불안정 → 스크립트/JSON은 **bash heredoc 또는 python으로 기록**한다(Write/Edit 툴이 파일을 잘리게 하거나 널바이트를 넣을 수 있음). 렌더 이미지 파일도 기존 파일 덮어쓰기 대신 새 이름 사용.
- 거절 사유는 "관점의 차이일 뿐, 확신이 아주 조금 부족" 톤 유지(회사·사업 폄하 금지).
- 투자 검토는 사용자 선호상 일반인보다 다소 공격적인 시각으로 쓰되, 사실에 근거해 긍정/부정 균형을 맞춘다.
