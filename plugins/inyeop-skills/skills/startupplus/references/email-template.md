# 투자 거절 메일 템플릿 (박인엽/패스트벤처스)

기본 동작으로 **점수와 무관하게 항상** 거절 메일을 생성한다(거절이 디폴트). 회사별 Word 1개: `투자 거절 메일(회사명).docx`.

## 실행
```bash
python3 scripts/make_rejection_email.py email.json <출력폴더>
```
email.json = 단일 dict 또는 dict 리스트. 키:
- `company` 회사명 (본문 'OOOOO 사'에 사용)
- `ceo` 대표명 ('대표' 직함 자동 부가)
- `story` 도메인 스토리 ('대표님의 OOO에 대한 재밌는 스토리'의 OOO)
- `strength` 강점 1개 ('(b) ...'에 삽입. 주로 시장 매력/핵심 강점. 팀 전문성은 (a)로 고정)
- `negative` 거절 사유 한 문장. 단점 2~3개를 녹이고 "다만, …관점에서 내부 설득이 결과적으로는 잘 이루어지지 못 했던 것 같습니다." 구조 유지.

## 원문 템플릿 (고정 문장 — 그대로 유지)
```
안녕하세요 {ceo} 대표님, 패스트벤처스의 박인엽입니다.
귀한 시간 내주시고 회사와 사업에 대해 소개 주셔서 다시 한 번 감사 드립니다.
대표님의 {story}에 대한 재밌는 스토리에 많이 공감이 되었습니다.
저희쪽에서 빠르게 투자 검토에 대한 의견을 전달 드리는 것을 선호하실 것 같아, 충분한 시간을 두고 오래오래 심사숙고하기 보다는, 최대한 빠르게 내부 논의를 통하여 결론을 내어보았습니다.
결과적으로, 저희 패스트벤처스는 이번에 {company} 사에 대한 투자를 진행하기 조금 어려울 것 같습니다.
(a) 대표님의 팀을 운영하시는 전문성, (b) {strength} 등 긍정적인 요소들이 많다고 느껴졌기 때문에 더 고민이 되었는데요,
{negative}
본 검토 의견은, 저희 패스트벤처스가 가지는 관점의 차이에서 기인한 것일 뿐이고, 회사에 대해 가지는 확신의 크기가 아주 조금 부족했기 때문이지, 절대 회사와 사업 자체에 대해 부정적으로 생각하여 투자를 못 하게 된 것은 아님을 꼭 말씀 드리고 싶습니다.
다음에 다른 기회로 또 인사 드릴 수 있으면 좋겠습니다.
감사합니다.
박인엽 드림.
```

## 작성 규칙
- **강점 1개**: 보고서의 긍정 검토의견/시장 매력에서 가장 강한 1개를 (b)에 담는다. (a) 팀 전문성은 항상 고정.
- **단점 2~3개**: 보고서의 부정 검토의견을 바탕으로 2~3개를 `negative` 한 문장에 자연스럽게 녹인다. 항상 완곡하게("아직 ~ 단계", "~까지의 시간/확장 속도 관점에서"). 대표 개인 의존도처럼 민감한 지적은 부드럽게 또는 생략.
- 톤: 따뜻하고 체면을 세워주는 거절. "관점의 차이일 뿐 / 확신이 아주 조금 부족" 프레임 유지. 회사·사업 폄하 금지.

## 실제 예시 (story / strength / negative)
- **폴미**(송진욱) — story: "영상의 맥락을 스스로 이해하는 AI" / strength: "글로벌 AI 미디어·숏폼 시장의 매력도" / negative: "다만, 이미 다수의 글로벌 플레이어가 자리한 시장에서 동사만의 기술적 해자가 충분히 입증되기까지의 과정과, 숏폼 생성·커머스·미디어 자산으로 다소 넓게 펼쳐진 사업 영역의 확장 속도 관점에서 내부 설득이 결과적으로는 잘 이루어지지 못 했던 것 같습니다."
- **로그미**(박정원) — story: "데이터로 건강을 정밀하게 관리하는 헬스케어" / strength: "이미 흑자를 달성하신 탄탄한 수익 구조와 디지털 헬스케어 시장의 매력도" / negative: "다만, 핵심 성장 동력인 글로벌 파트너십이 아직 확정 전 논의 단계라는 점과, 매출의 상당 부분을 차지하는 구축형(일회성) 매출이 운영형 반복매출로 전환되는 속도 관점에서 내부 설득이 결과적으로는 잘 이루어지지 못 했던 것 같습니다."
- **이노아울**(임진묵) — story: "환자마다 다른 아토피를 정밀하게 진단하는 의료 플랫폼" / strength: "정밀의료 시장의 미충족 수요와, 이미 탄탄하게 갖추신 연구·임상 기반" / negative: "다만, 바이오 분야 특성상 대규모 임상 검증과 인허가까지 필요한 시간과 자본의 규모, 그리고 본격적인 매출이 발생하기 전 단계에서의 상용화 속도 관점에서 내부 설득이 결과적으로는 잘 이루어지지 못 했던 것 같습니다."
- **포어덱스**(정대훈) — story: "블록체인 온체인 데이터로 투자의 기준을 만드는" / strength: "온체인 데이터 분석 분야에서 대표님이 보유하신 독보적인 전문성" / negative: "다만, 아직 유료 매출이 초기 단계라는 점과, 글로벌 선도 플랫폼들이 이미 자리한 경쟁 환경, 그리고 암호자산 시장의 높은 변동성 관점에서 내부 설득이 결과적으로는 잘 이루어지지 못 했던 것 같습니다."
- **가이드웨이컨설팅**(정민웅) — story: "K-뷰티 브랜드의 미국 진출을 새롭게 여는" / strength: "K-뷰티 북미 진출 시장의 매력도와, 이미 갖추신 현지 유통·물류 네트워크" / negative: "다만, 아직 누적 매출과 반복매출의 규모가 초기 단계라는 점과, 크리에이터 커머스·K-뷰티 진출 경쟁이 치열한 환경에서 동사만의 데이터 해자가 충분히 입증되기까지의 확장 속도 관점에서 내부 설득이 결과적으로는 잘 이루어지지 못 했던 것 같습니다."
